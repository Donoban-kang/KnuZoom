# KnuZoom 설계서 — 참가자 측 회의 녹화(mp4)

- 작성일: 2026-10-19
- 상태: 검토 대기
- 선행 설계: `docs/superpowers/specs/2026-10-18-knuzoom-design.md` (자동 음소거 해제)

## 1. 목적과 배경

### 1.1 상황
- A대학 주최 Zoom 회의에 B대학이 **참가자**로 참여한다. Zoom 녹화는 호스트 권한이며, 호스트 계정 설정상 참가자 로컬 녹화 권한을 받을 수 없는 경우가 있다.
- 참석 기관(A·C·D대학)의 **녹화 동의는 받을 수 있는 상황**이다(검토 결과 (나)안).

### 1.2 목표
- B대학 PC에서 회의 화면·소리를 **mp4**로 녹화한다.
- 비밀 녹화가 되지 않도록 **동의 확인·녹화 사실 표시·파일 관리**를 기능으로 강제한다.

### 1.3 성공 기준
- 동의 확인을 거치지 않으면 녹화를 시작할 수 없다.
- 녹화 중에는 모든 참석 기관이 B대학 영상에서 "녹화 중" 표시를 볼 수 있다.
- 녹화 파일은 일반 플레이어(Windows 미디어 플레이어 등)에서 재생되며, 프로그램이 비정상 종료돼도 그때까지의 내용이 남는다.
- B대학 회의실 소리는 **Zoom에서 음소거 해제된 동안만** 녹화된다.

### 1.4 범위 제외
- Zoom 창만 골라 녹화(검은 화면 위험 — 실기 검증 후 별도 검토)
- Zoom 채팅 자동 전송, 클라우드 업로드, 녹화 파일 자체 암호화(디스크 암호화 BitLocker 권장으로 대체)
- 녹화 편집·자막·회의록 자동 작성

## 2. 기관 차원 선행 조건 (일반적인 공공기관 절차 기준, 기관 확정 절차는 별도 확인)
| 항목 | 내용 |
|---|---|
| 동의 | 녹화 목적·항목(얼굴·음성)·보유기간을 참석 기관에 고지하고 동의 확보. 회의 개최 공문에 녹화 사실 명시 권장(개인정보 보호법 제15조 — 추정) |
| 개인정보파일 | 녹화물을 반복 축적·운영 시 공공기관 개인정보파일 등록 대상 여부 검토(같은 법 제32조 — 추가 확인 필요) |
| 기록물 | 회의 녹화물의 공공기록물 해당 여부·보존기간 확인(기록관리 부서 — 추가 확인 필요) |
| 정보보안 | 저장 PC 접근 통제, BitLocker 등 디스크 암호화, 외부 반출 절차 |
| 주최 기관 협의 | A대학에 녹화 방식·표시 방법을 사전 공유 |

## 3. 결정 사항 (사용자 승인: 추천안)
| 항목 | 결정 |
|---|---|
| 녹화 범위 | Zoom을 표시하는 **모니터 전체** |
| 녹화 알림 | **가상 카메라 영상에 "● 녹화 중 (B대학)" 표시** + 안내 문구 클립보드 복사(진행자가 채팅에 붙여넣기) + 진행자 창·트레이 표시 |
| 기본 보관기간 | **30일** 경과 시 KnuZoom 시작 때 삭제 여부 확인(자동 삭제 없음) |
| 저장 형식 | mp4 (H.264 영상 + AAC 음성), 비정상 종료 대비 조각(fragmented) mp4 |

## 4. 전체 구조

```
                 ┌─────────────── KnuZoom ───────────────┐
[추적 카메라] → │ 영상 입출력 ─(녹화 중이면 표시 합성)→ 가상 카메라 → Zoom(B대학 영상)
                 │                                        │
[모니터 화면] ──→│ FFmpeg(화면 캡처 + H.264 인코딩) ←─ 음성(s16le 파이프)
[스피커 소리] ──→│ 음성 믹서: 스피커 루프백 + 회의실 마이크(해제 중일 때만)
[회의실 마이크] →│                                        │
                 │ 녹화 관리자: 동의 확인 → 시작/종료 → 동의 기록·해시 저장
                 └────────────────────────────────────────┘
                              ↓
          문서\KnuZoom 녹화\20261019_1400_회의명.mp4 + .txt(동의 기록)
```

### 4.1 모듈 (`src/knuzoom/recording/`)
| 모듈 | 책임 | 플랫폼 |
|---|---|---|
| `consent.py` | 동의 정보(`ConsentRecord`) 검증, 동의 기록 텍스트 생성 | 공통(시험 가능) |
| `storage.py` | 파일 이름 생성(금지 문자 제거), 디스크 여유 공간 확인, 보관기간 경과 파일 찾기 | 공통 |
| `overlay.py` | "● 녹화 중 (기관명)" 이미지를 한 번 그려 두고 프레임에 합성 | 공통(한글 글꼴은 Windows `malgun.ttf`, 없으면 기본 글꼴) |
| `audio_mix.py` | 루프백·마이크 블록 혼합, 마이크 게이트(해제 중만 통과, 20ms 페이드) | 공통(순수 계산) |
| `ffmpeg_cmd.py` | FFmpeg 명령줄 생성 | 공통 |
| `recorder.py` | FFmpeg 프로세스·음성 스레드 수명 관리, 자동 종료 조건 | 공통(프로세스·장치는 주입) |
| `devices_windows.py` | WASAPI 루프백·마이크 장치 열기(`soundcard`) | Windows |

UI(`ui.py`)에는 [● 녹화] / [■ 녹화 종료] 버튼, 녹화 시간 표시, 동의 확인 창, 보관기간 경과 파일 확인 창을 추가한다.

## 5. 세부 설계

### 5.1 동의 확인 창 (녹화 시작의 유일한 경로)
- 입력: 회의명(필수), 동의 받은 기관(설정 `consent_parties`, 기본 `["A대학","C대학","D대학"]` — **모두 체크해야 시작 가능**), 동의 방법(사전 공문 / 회의 시작 시 구두 / 기타+내용), 녹화 목적(필수, 기본 "회의록 작성"), 보관기간(일, 기본 30, 1~3650).
- 검증 실패 시 시작 버튼 비활성 + 사유 표시.
- 시작 시 안내 문구를 클립보드에 복사하고 "Zoom 채팅에 붙여넣어 주세요" 안내:
  `[안내] {site_name}에서 이 회의를 녹화하고 있습니다. (목적: {목적}, 보관: {N}일)`

### 5.2 동의 기록 파일 (.txt, mp4와 같은 이름)
```
KnuZoom 녹화 동의 기록
회의명: ○○협의회
녹화 기관: B대학
동의 기관: A대학, C대학, D대학
동의 방법: 사전 공문
녹화 목적: 회의록 작성
보관기간: 30일 (삭제 예정일: 2026-11-18)
녹화 시작: 2026-10-19 14:00:05
녹화 종료: 2026-10-19 15:12:40
파일: 20261019_1400_○○협의회.mp4
SHA-256: (종료 시 계산)
```
- 시작 시 작성, 종료 시 종료 시각·SHA-256을 추가(감사 대응용 무결성 근거).

### 5.3 화면 캡처·인코딩 (FFmpeg)
- 입력: `ddagrab`(Desktop Duplication) 모니터 번호 = 설정 `recording_monitor`(기본 0), 30fps. 마우스 포인터 포함 안 함.
- 음성: KnuZoom이 섞은 48kHz 스테레오 s16le를 표준입력으로 전달, `aresample=async=1`로 동기 보정.
- 인코더: `h264_mf`(Windows Media Foundation, 하드웨어 가속 활용), 음성 `aac` 160kbps.
- 컨테이너: `-movflags +frag_keyframe+empty_moov+default_base_moof` (비정상 종료 시에도 재생 가능).
- 배포: **LGPL 빌드 FFmpeg**(GPL 인코더 x264 미포함)를 설치 파일에 포함하고 라이선스 문서 동봉(라이선스 조건 추가 확인 필요).
- `ddagrab` 출력 형식에 따라 `hwdownload,format=bgra` 변환 필요 여부는 Windows 실기·CI에서 확정.

### 5.4 음성 혼합과 마이크 게이트
- 루프백(상대 기관 소리)과 마이크(B대학 회의실)를 20ms 블록 단위로 읽어 혼합, 클리핑 방지(합 후 -1~1 제한).
- 마이크 게이트 열림 조건: 엔진 상태가 **해제(muted=False)** 이고, (Zoom에서 확인됨 **또는** 상태 추정 모드). 그 외(음소거·미확인·긴급정지)는 닫힘.
- 게이트 전환 시 20ms 페이드로 딸깍 소리 방지.
- 장치 오류: 루프백 실패 → 녹화 계속 + 경고 "녹화: 스피커 소리 녹음 실패", 마이크 실패 → 녹화 계속 + 경고.

### 5.5 "녹화 중" 표시 합성
- 가상 카메라로 보내는 프레임 우상단에 반투명 배경 + 빨간 원 + "녹화 중 ({site_name})" (설정 `site_name`, 기본 "B대학").
- 표시 이미지는 녹화 시작 시 한 번 그려 두고 프레임마다 알파 합성(부하 최소화).
- 녹화 중에는 표시를 끌 수 없다(설정 없음).

### 5.6 종료 조건
| 조건 | 동작 |
|---|---|
| [■ 녹화 종료] | FFmpeg에 정상 종료 요청(표준입력 닫기 + `q`), 10초 내 미종료 시 강제 종료 |
| Zoom 회의 창이 10초 이상 없음 | 자동 종료 + 안내 |
| 디스크 여유 2GB 미만 | 자동 종료 + 경고 |
| FFmpeg 비정상 종료 | 녹화 중단 경고, 이미 기록된 부분은 보존 |
| KnuZoom 종료 | 녹화를 먼저 정상 종료한 뒤 종료 |
| 긴급 정지(Ctrl+Alt+K) | **녹화는 계속**(마이크 게이트만 닫힘) |
- 시작 전 디스크 여유 5GB 미만이면 시작 거부.

### 5.7 저장·보관
- 저장 폴더: 설정 `recording_dir`, 기본 `문서\KnuZoom 녹화`.
- 파일 이름: `YYYYMMDD_HHMM_{회의명}.mp4` (`\/:*?"<>|` 제거, 30자 제한, 중복 시 `_2`).
- KnuZoom 시작 시 동의 기록의 삭제 예정일이 지난 녹화 목록을 보여 주고, **확인 후에만** mp4·txt를 함께 삭제. "나중에"를 고르면 다음 시작 때 다시 묻는다.

### 5.8 설정 추가
`site_name`, `consent_parties`, `recording_dir`, `recording_monitor`, `retention_days`(30), `min_free_gb_start`(5), `min_free_gb_stop`(2) — 기존 설정 검증(`sanitize_settings`) 규칙에 범위 추가.

## 6. 오류 대응 원칙
- 녹화 기능의 어떤 오류도 **음소거 자동 제어를 멈추거나 마이크를 여는 방향으로 영향을 주지 않는다**(별도 스레드·예외 격리).
- 녹화 실패는 진행자 창에 별도 줄로 표시(기존 경고와 섞지 않음).
