# KnuZoom 설치·사전 설정 안내 (B대학 회의실 Windows PC)

> 표시가 **(확인 필요)** 인 항목은 실제 PC·Zoom 버전에서 확인한 뒤 이 문서를 갱신한다.

## 0. 사전 확인 (회의 전)
| 확인 대상 | 내용 | 확인 |
|---|---|---|
| A대학(주최) | 회의 설정에서 **참가자 스스로 음소거 해제 허용**이 켜져 있는지 | ☐ |
| 우리 기관 전산 부서 | 가상 카메라 드라이버(OBS Studio) 설치 승인 | ☐ |
| 우리 기관 개인정보 담당 | 얼굴 **검출**(식별 아님, 저장 안 함) 사용 사전 확인 | ☐ |

## 1. 설치
1. **OBS Studio** 설치 (가상 카메라 드라이버 "OBS Virtual Camera" 제공). OBS 프로그램 자체를 실행할 필요는 없다.
2. `KnuZoom` 폴더(`dist/KnuZoom/`)를 PC에 복사하고 `KnuZoom.exe` 바로가기를 바탕화면에 만든다.
   - 개발 환경에서 직접 실행할 경우: Python 3.11 설치 후 `pip install -e .[windows]` → `python -m knuzoom`
   - 실행파일 만들기: `pip install -e .[windows,dev]` → `pyinstaller knuzoom.spec`

## 2. Zoom Workplace 설정
1. **비디오 카메라**: 설정 > 비디오 > 카메라를 **"OBS Virtual Camera"** 로 선택 (KnuZoom 실행 중이어야 영상이 나온다).
2. **전역 단축키**: 설정 > 키보드 단축키 > "오디오 음소거/음소거 해제(Alt+A)"의 **전역 단축키 사용** 체크 **(확인 필요)**.
3. **버튼 문구 확인**: Zoom 테스트 회의에 참가한 상태에서 `python scripts/probe_zoom.py` 를 음소거 상태/해제 상태에서 각각 실행해 마이크 버튼 이름을 확인한다.
   - 확인 결과 기록: 음소거 상태 버튼 = `__________` / 해제 상태 버튼 = `__________` / 회의 창 제목 = `__________`
   - KnuZoom [⚙ 설정]의 "음소거 상태 버튼 문구", "해제 상태 버튼 문구", "Zoom 회의 창 제목"에 반영한다.
   - 상태를 읽을 수 없으면 KnuZoom은 "상태 추정 중" 예비 모드로 동작한다(아래 [상태 맞추기] 참고).
4. 실제 추적 카메라의 Zoom 표시 이름 기록(비상용): `__________`

## 3. 첫 실행·보정
1. `KnuZoom.exe` 실행 → 작은 창(항상 위)과 트레이 아이콘이 나타난다. 시작 상태는 항상 **음소거**.
2. 카메라가 넓게 비출 때 [넓은 장면 저장], 발언자를 확대했을 때 [확대 장면 저장]을 누른다(각 약 2초 측정). 기준값이 자동 계산·저장된다.
3. 설정 파일: `%APPDATA%\KnuZoom\settings.json`, 로그: `%APPDATA%\KnuZoom\logs\` (상태 전환만 기록, 영상·이미지는 저장하지 않음).

## 비상 운영 절차 (회의 진행자용 — 인쇄해 회의실에 비치)

| 상황 | 할 일 |
|---|---|
| 원치 않게 소리가 나가거나 음소거됨 | Zoom 화면의 **마이크 버튼** 또는 **Alt+A** 로 직접 조작. 다음 카메라 전환(넓게↔확대) 전까지 그대로 유지된다. |
| 즉시 소리를 막아야 함 | **Ctrl+Alt+K** (즉시 음소거 + 자동 OFF). 말하려면 Zoom 마이크 버튼으로 해제. [자동 ON]을 다시 눌러도 그때 확대돼 있던 발언자는 음소거가 유지되고(창에 "긴급 정지 후 대기" 표시), 카메라가 넓은 장면으로 돌아갔다가 다시 확대될 때부터 자동 해제된다. |
| 자동을 끄고 사람이 진행 | KnuZoom 창 **[자동 ON/OFF]** 를 OFF. 이후 마이크는 Zoom 버튼으로만 조작. |
| 자동이 반대로 동작함 | KnuZoom 창 **[상태 맞추기]** → 지금 Zoom 마이크 상태를 선택. 답하는 사이 KnuZoom이 마이크를 조작했다는 안내가 나오면 Zoom 상태를 다시 보고 한 번 더 맞춘다. |
| KnuZoom이 멈춤 / B대학 영상이 끊김 | ① 작업 관리자(Ctrl+Shift+Esc)에서 **KnuZoom.exe 종료** ② Zoom 하단 [비디오 중지] 옆 **∧** 메뉴 → 카메라를 **실제 추적 카메라**(위 2-4 기록 이름)로 변경 ③ 마이크는 Zoom 버튼으로 수동 운영 |
| "호스트(A대학)가 해제를 막았을 수 있음" 표시 | A대학 진행자에게 채팅으로 음소거 해제 허용 요청, 또는 Zoom의 "음소거 해제 요청"에 수락 |
| "카메라 끊김" 표시 | 카메라 USB·전원 확인. 자동으로 음소거되며, 다시 연결되면 경고가 사라진다. |
