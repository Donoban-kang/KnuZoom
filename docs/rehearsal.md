- 비상 절차 참고: `docs/install.md` "비상 운영 절차"

| # | 시험 항목 | 방법 | 합격 기준 | 측정값 | 통과 |
|---|---|---|---|---|---|
| 1 | 확대 → 음소거 해제 | 발언자가 말해 카메라 확대, 확대 완료부터 "발언 가능"까지 시간 측정 (10회) | 최대 **2.5초 이내** | 최대 ___초 | ☐ |

| 3 | 고개 숙임 | 확대 상태에서 발언자가 10초간 고개 숙임 | 해제 상태 유지 | | ☐ |
| 4 | 카메라 분리 | 카메라 USB 분리 → 재연결 | 즉시 음소거 + "카메라 끊김", 재연결 후 경고 해제 | | ☐ |
| 5 | 긴급 정지 | Ctrl+Alt+K | **1초 이내** 음소거 + 자동 OFF | ___초 | ☐ |
| 6 | 호스트 차단 | 호스트가 "참가자 스스로 해제 허용" OFF 후 확대 | "호스트(A대학)가 해제를 막았을 수 있음" 표시 | | ☐ |
| 7 | 수동 조작 존중 | 해제 상태에서 진행자가 Zoom에서 직접 음소거 | 다음 전환까지 음소거 유지 | | ☐ |
| 8 | 회의 퇴장/재입장 | 회의 나갔다가 다시 참가 | 나가 있는 동안 "대기", 재입장 시 현재 상태 적용 | | ☐ |
| 9 | 보정 | [넓은 장면 저장] → [확대 장면 저장] → KnuZoom 재시작 | 기준값 갱신·재시작 후 유지 | wide ___ / zoom ___ | ☐ |
| 10 | 개인정보 | 회의 후 `%APPDATA%\KnuZoom` 확인 | 로그에 상태 전환만 기록, 영상·이미지 파일 없음 | | ☐ |
| 11 | 비상 전환 | 회의 중 작업 관리자로 KnuZoom.exe 강제 종료 → 진행자가 비상 운영 절차만 보고 카메라 전환 | **30초 이내** 영상 복구, Zoom 버튼으로 수동 음소거/해제 가능 | ___초 | ☐ |
| 12 | 녹화: 동의 미체크 | [● 녹화] → 기관 하나라도 체크 안 함 | [녹화 시작] 비활성 | | ☐ |
| 13 | 녹화: 표시 | 녹화 시작 후 호스트 PC 화면에서 B대학 영상 확인 | "● 녹화 중 (기관명)" 보임 | | ☐ |
| 14 | 녹화: 음소거 중 소리 | 넓은 장면(음소거)에서 회의실 대화 → 녹화 파일 재생 | 회의실 대화가 녹화에 없음 | | ☐ |
| 15 | 녹화: 1시간 | 1시간 녹화 | 끊김 없음, 소리·영상 싱크 어긋남 없음, 용량 기록 | ___GB | ☐ |
